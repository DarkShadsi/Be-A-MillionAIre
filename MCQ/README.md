# Question bank

Place the group's reviewed questions in questions.csv. The current file is a header-only authoring template.

Columns: id, category, difficulty, text, choice_a, choice_b, choice_c, choice_d, correct_choice_id, clue.
Use unique IDs, category identifiers from Category.java, difficulty EASY/MEDIUM/HARD and answer A/B/C/D.
Quote fields containing commas, double quotes or line breaks using normal CSV escaping. A spreadsheet editor can save UTF-8 CSV.

Each of the eight categories needs at least five questions at each difficulty (120 questions minimum overall). More than five per difficulty allows the selected question subset to vary. Choices and question order are shuffled every round. Random selection can occasionally repeat an earlier ordering.

Check each answer and clue against the group's activity sources. Ask a second person to review the correct answer, wording and difficulty. Keep authoring references with the content-review work. Only reviewed course questions belong in this file.
